==================== [CONTEXTO DE LA APLICACION] ====================

Resumen general:
- Proyecto: Inventluis370 (backend Laravel + MongoDB, frontend web y app Android).
- Objetivo: gestion de inventario, equipos, servicios tecnicos, solicitudes de repuestos, garantias, notificaciones, reportes, RMA, tarifas y estadisticas.
- Android consume API REST bajo /api con token Bearer.

Arquitectura y contratos principales:
- Autenticacion:
  - POST /api/login
  - POST /api/logout
  - POST /api/token/extend
  - POST /api/password/forgot
  - POST /api/password/verify
  - POST /api/password/reset
- Modulos CRUD:
  - /api/empresas
  - /api/usuarios
  - /api/equipos
  - /api/propiedad-equipos
  - /api/servicios
  - /api/garantias
  - /api/repuestos
  - /api/inventario
  - /api/solicitud-repuestos
  - /api/notificaciones
  - /api/reportes
  - /api/rma
  - /api/tarifas-servicio
- RBAC / permisos:
  - GET /api/rbac
  - GET /api/permissions
  - PUT /api/permissions
  - POST /api/permissions/reset
  - GET /api/permissions/user/{id}
  - PUT /api/permissions/user/{id}
  - POST /api/permissions/user/{id}/reset
- Dashboard y estadisticas:
  - GET /api/dashboard
  - GET /api/stats/{module}
  - POST /api/stats/batch

Estado Android relevante (resumen operativo):
- BASE_URL configurable por flavor en gradle.properties.
- Tema claro/oscuro con toggle global (iconos solicitados).
- Pantallas con topbars estandarizadas y recarga por gesto en modulos clave.
- Estadisticas por modulo con tarjetas y mini-barras.
- Validaciones numericas reforzadas para evitar guardar 0 por conversion silenciosa.

Archivos clave Android:
